# The Male Order Erise

Luxury Menswear Atelier digital storefront featuring tailored menswear collections:
- **Office casuals**
- **Kurta-pyjama**
- **Blazers**

## Highlights
- **Mobile-First UX**: Responsive mobile layout with animated burger navigation and quick-action filters.
- **Direct WhatsApp Inquiry**: Seamless integration with WhatsApp Business (`+91 9106688717`) with pre-filled product details.
- **Store Locator**: Embedded Google Maps location and directions to the Ahmedabad atelier.
- **GSAP Animations**: Scroll-triggered reveals, smooth micro-interactions, and transitions.

## Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP + @gsap/react + ScrollTrigger
- **Icons**: Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Production Build
```bash
npm run build
```
The production assets will be generated in the `out/` directory, ready to deploy to Netlify, Vercel, or any static hosting platform.
